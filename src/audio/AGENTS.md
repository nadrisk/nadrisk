# Audio
- Enabled master limiting ends with a stereo-linked lookahead peak guard after the compressor, before the shared final output and tape/meter taps; bypass remains explicit.
- Sampler ARM requests capture before asynchronous engine setup and uses Safari's play-and-record session; disarm restores playback, and errors distinguish permission, device and setup failures.
- Per-slot effects live in src/audio/effects.ts as rebuildable chains whose order is the audio order; custom DSP (bitcrush, envelope follower) runs in inline AudioWorklets so no extra files need hosting.
- Advanced rhythmic, ducking, multiband and buffer-capture processing uses inline AudioWorklets on the shared audio context, so effects remain audio-clock driven without hosted DSP files.
- Tone registers only one AudioWorklet module per context, so NAD processors (including the tape recorder in src/audio/tapeWorklet.ts) must be concatenated into the single loadWorklets bundle; Signalsmith Stretch is the exception and registers its self-contained WASM module directly on the raw context.
- Dynamics effect displays read silent analyser taps on each effect's pre/post nodes, so meters show live signal without altering the audible chain.
- Drum voices are per-kind machines in src/audio/voices.ts with optional fields filled by drumDefaults(), so older sets load without migration.
- Drum recipes live in drumPresets.ts and load complete copied sounds; an optional preset ID sets reset homes without overwriting edited values on recall.
- Pad hits never build buffers or curves (sample variants pre-baked at idle, drive curves cached; max 6 ringing voices per pad), so every instrument triggers instantly.
- Voices expose stop() (instant cut for chokes, cap, transport) and release(at, r) (fade from the current level that only ever shortens a tail); retriggers and live release edits re-time a pad's ringing tails with its current release, so release changes are heard immediately.
- Synth and siren LFOs run from one free-running oscillator per slot in the engine (TRIG mode builds a per-note one), so modulation phase continues across notes.
- Effect additions are limited by FX_COST against MAX_FX_LOAD across all slots, so the groovebox can't be overloaded; loaded sets over budget still play.
- The channel insert EQ is configured by configureEq() for both audio and screen (screen reads getFrequencyResponse from an offline mirror), so the drawn curve is the real response.
- tape.delay~ is one tape loop read by three serial heads with feedback scaled by 1/sqrt(active heads) and a spring tank fed by input plus echoes, so MODE changes never destabilise the loop.
- POLY REESE mode (src/audio/reese.ts) is mono with its own saved params beside POLY's and a centred unfiltered sub, so switching modes never overwrites either sound.
- ACID is the 808 engine's second mode (bass.mode) with its own params beside the 808's, loading old POLY-ACID pads as 808 ACID; one oscillator feeds pooled nonlinear TPT ladders in the shared bundle with velocity accents and phrase slides. Pool state resets at note start, gains boot silent with pre-start cancellations, inactive inputs skip DSP; accented onsets ramp cutoff and VCA over accent-scaled milliseconds so smoothing never restarts envelopes.
- Each slot's voices enter through a zero-time DelayNode (outs[i].input), because the audio wrapper's per-connect cycle check stops at delays; without it every hit walked the whole downstream graph.
- Drum presets can set optional gain (post-filter level) and grit (cached 6-bit staircase + 14 kHz lowpass for 909-ROM hat character); both default neutral so older sets sound unchanged.
- BRK pools Signalsmith Stretch WASM voices on the shared raw context, keeping pitch/duration independent and taps warm.
- Granular voices use shared smooth windows, density-aware overlap with energy compensation and bounded stereo spread, so cloud playback stays continuous without raising the global grain budget.
- LASER uses three oscillators and a shared attack/decay trajectory for audio/display; missing saved attack is zero to preserve recall.
- Transient slices (src/audio/slices.ts) cache one onset curve per buffer; SLCE sensitivity only re-picks peaks, and sliced sampler pads are mono (chords become strum/arp slice sequences).
- morph.flt~ moves both biquads with one LFO through detune and rebuilds the LFO source only on wave change or RTRG note triggers.
- NADRISK malfunction mode is session-only and crossfades pre-built, dry master stages in performance.ts (OTT, then the nad-failure worklet: loudness-reactive sub-octaves, diode drive, slow pump) before the limiter, so entering it never builds nodes or cuts audio.
- Unlicensed hosts (src/lib/origin.ts allowlist) force a permanent NADRISK lock for the session; add every new domain to that allowlist before connecting it.
- acid.drive~ is a "Da Funk" chain (mid push → one cached asymmetric clip curve → TONE lowpass → MID peak → heavy fast compressor); it keeps the "drive" key as SUST and derives TONE from old "tone" Hz values, so older sets and sequencer mods still load.
- Synth SPEC mode (src/audio/spectral.ts) is a separate voice path chosen by synth.mode with its own saved spec params, so additive sounds and old sets are untouched.
- SPEC GATE is the nad-specsynth FFT gate (src/audio/specSynthWorklet.ts: Hann STFT 75% overlap, peak-relative threshold, 6 dB soft knee) in pooled nodes (max 12, every SPEC note takes one even at GATE 0, returned on cleanup, oldest stolen when full) since worklets never self-terminate; it posts its retained-bin mask for the SPC screen.
- Chorus, flanger, phaser and tape delay WIDTH is a shared mid/side stage (side highpassed at 150 Hz) fed by two decorrelated signals; a missing width param means 0 so older sets stay mono.
- Chorus (nad-juno, Juno-60 modes) and flanger (nad-ada, ADA-style wide sweep) are dedicated wet-only BBD worklets in src/audio/modWorklets.ts with MAN, ENV and internal mid/side WIDTH, so their character never depends on the shared delay-line code.
- Sampler INPUT mode (src/audio/liveInput.ts) keeps one shared mic stream routed into the armed pad's outs[i].input and captures via the nad-rec worklet in the shared bundle; armed state is session-only and never saved.
- Reverb is our own nad-reverb FDN worklet (pre-delay + 120 Hz HP, 5 DENS input diffusers, two decorrelated 8-line Householder networks each with an LFO-modulated in-loop allpass, DAMP lowpass, exact T60 gains, empirically loudness-matched output) with the dry-hold reverbMixLaw in createFx (tape delay MIX shares it); recalibrate the loudness fit in setup() and its test if the topology changes.
- GEN generators are pure seeded functions in patternGen.ts; the hook writes results in one undo step, so they stay testable and undoable.
