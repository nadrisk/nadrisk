# Audio
- Enabled master limiting ends with a stereo-linked lookahead peak guard after the compressor, before the shared final output and tape/meter taps; bypass remains explicit.
- Sampler ARM requests capture before asynchronous engine setup and uses Safari's play-and-record session; disarm restores playback, and errors distinguish permission, device and setup failures.
- Per-slot effects live in src/audio/effects.ts as rebuildable chains whose order is the audio order; custom DSP (bitcrush, envelope follower) runs in inline AudioWorklets so no extra files need hosting.
- Advanced rhythmic, ducking, multiband and buffer-capture processing uses inline AudioWorklets on the shared audio context, so effects remain audio-clock driven without hosted DSP files.
- Tone registers only one AudioWorklet module per context, so NAD processors (including the tape recorder in src/audio/tapeWorklet.ts) must be concatenated into the single loadWorklets bundle; Signalsmith Stretch is the exception and registers its self-contained WASM module directly on the raw context.
- Dynamics effect displays read silent analyser taps on each effect's pre/post nodes, so meters show live signal without altering the audible chain.
- Drum voices are per-kind machines in src/audio/voices.ts with optional fields filled by drumDefaults(), so older sets load without migration.
- Drum recipes live in drumPresets.ts and load complete copied sounds; an optional preset ID sets reset homes without overwriting edited values on recall.
- Pad hits never build buffers or curves (sample variants pre-baked at idle, drive curves cached; max 6 ringing voices per pad), so every instrument triggers instantly.
- Voices expose stop() (instant cut for chokes, cap, transport) and release(at, r) (fade from the current level that only ever shortens a tail); retriggers and live release edits re-time a pad's ringing tails with its current release, so release changes are heard immediately.
- Synth and siren LFOs run from one free-running oscillator per slot in the engine (TRIG mode builds a per-note one), so modulation phase continues across notes.
- Effect additions are limited by FX_COST against MAX_FX_LOAD across all slots, so the groovebox can't be overloaded; loaded sets over budget still play.
- The channel insert EQ is configured by configureEq() for both audio and screen (screen reads getFrequencyResponse from an offline mirror), so the drawn curve is the real response.
- tape.delay~ is one tape loop read by three serial heads with feedback scaled by 1/sqrt(active heads) and a spring tank fed by input plus echoes, so MODE changes never destabilise the loop.
- POLY REESE mode (src/audio/reese.ts) is mono with its own saved params beside POLY's and a centred unfiltered sub, so switching modes never overwrites either sound.
- ACID is the 808 engine's second mode (bass.mode) with its own params beside the 808's, loading old POLY-ACID pads as 808 ACID; one oscillator feeds pooled nonlinear TPT ladders in the shared bundle with velocity accents and phrase slides. Pool state resets at note start, gains boot silent with pre-start cancellations, inactive inputs skip DSP; accented onsets ramp cutoff and VCA over accent-scaled milliseconds so smoothing never restarts envelopes.
- Each slot's voices enter through a zero-time DelayNode (outs[i].input), because the audio wrapper's per-connect cycle check stops at delays; without it every hit walked the whole downstream graph.
- Drum presets can set optional gain (post-filter level) and grit (cached 6-bit staircase + 14 kHz lowpass for 909-ROM hat character); both default neutral so older sets sound unchanged.
- BRK pools Signalsmith Stretch WASM voices on the shared raw context, keeping pitch/duration independent and taps warm.
- Granular voices use shared smooth windows, density-aware overlap with energy compensation and bounded stereo spread, so cloud playback stays continuous without raising the global grain budget.
- LASER uses three oscillators and a shared attack/decay trajectory for audio/display; missing saved attack is zero to preserve recall.
- Transient slices (src/audio/slices.ts) cache one onset curve per buffer; SLCE sensitivity only re-picks peaks, and sliced sampler pads are mono (chords become strum/arp slice sequences).
- morph.flt~ is two crossfaded biquads moved by one LFO through detune (no mutate twins); it rebuilds the LFO source only on wave change or RTRG note triggers.
- NADRISK malfunction mode is session-only and crossfades pre-built, dry master stages in performance.ts (OTT, then the nad-failure worklet: loudness-reactive sub-octaves, diode drive, slow pump) before the limiter, so entering it never builds nodes or cuts audio.
- Unlicensed hosts (src/lib/origin.ts allowlist) force a permanent NADRISK lock for the session; add every new domain to that allowlist before connecting it.
- acid.drive~ is a "Da Funk" chain (mid push → one cached asymmetric clip curve → TONE lowpass → MID peak → heavy fast compressor); it keeps the "drive" key as SUST and derives TONE from old "tone" Hz values, so older sets and sequencer mods still load.
- Synth SPEC mode (src/audio/spectral.ts) is a separate voice path chosen by synth.mode with its own saved spec params, so additive sounds and old sets are untouched.
- SPEC GATE is the nad-specsynth FFT gate (src/audio/specSynthWorklet.ts: Hann STFT 75% overlap, peak-relative threshold, 6 dB soft knee) in pooled nodes (max 12, every SPEC note takes one even at GATE 0, returned on cleanup, oldest stolen when full) since worklets never self-terminate; it posts its retained-bin mask for the SPC screen.
- Chorus, flanger, phaser and tape delay WIDTH is a shared mid/side stage (side highpassed at 150 Hz) fed by two decorrelated signals; a missing width param means 0 so older sets stay mono.
- Chorus (nad-juno, Juno-60 modes) and flanger (nad-ada, ADA-style wide sweep) are dedicated wet-only BBD worklets in src/audio/modWorklets.ts with MAN, ENV and internal mid/side WIDTH, so their character never depends on the shared delay-line code.
- Sampler INPUT mode (src/audio/liveInput.ts) keeps one shared mic stream routed into the armed pad's outs[i].input and captures via the nad-rec worklet in the shared bundle; armed state is session-only and never saved.
- Sampler REC is one key: threshold starts (nad-rec 1024-sample pre-roll, no latency trim) or NOTE mode punch in/out booked by the grid scheduler at the note's start/end; every finished take closes the mic and loads ONE-shot with an explicit sample root register.
- Piano PAD presets (keys) have their own XY: X sweeps BRT down to -0.25 (felt) and up to 1, Y sets dec (decay scale, saved only when moved) and release, attack fixed at 2 ms.
- Reverb is our own nad-reverb FDN worklet (pre-delay + 120 Hz HP, 5 DENS input diffusers, two decorrelated 8-line Householder networks each with an LFO-modulated in-loop allpass, DAMP lowpass, exact T60 gains, empirically loudness-matched output) with the dry-hold reverbMixLaw in createFx (tape delay MIX shares it); recalibrate the loudness fit in setup() and its test if the topology changes.
- GEN generators are pure seeded functions in patternGen.ts; the hook writes results in one undo step, so they stay testable and undoable.
- PRC engines (src/audio/idm.ts: NOIS, VCO, six ROUT patches each) are percussive-only: DECAY is clamped to IDM_MAX_DECAY, every feedback loop runs through a DelayNode with gain < 1 plus soft clip, and retired model ids map to an engine + routing on load, so old sets never ring long.
- PAD MIDI GRAND plays bundled Salamander recordings (src/assets/piano, src/audio/pianoSamples.ts) decoded once per context and re-pitched from the nearest root, so the piano is real and works offline.
- Phrase CHRD lock (arp.chordSync) walks TRNC/EUCL phrases through the chord tones (chordWalk, per-pad counter reset on the first phrase step) and snaps other phrases to the nearest tone; phrase playback order is arp.dir (legacy loop ignored) (key chord when Harmony is on) and plays one note per step via trigger noteIdx -1, so the phrase walks the chord instead of stacking it.
- Phrase SPRD is a live degree scale (spreadDeg, 0.5 = as written) applied at playback and on screen, never written into cells, so turning it back restores the pattern; double-tap ties use the pure tieSpan helper in tie.ts.
- hack~ (circuit bend) is the nad-hack worklet in src/audio/hackWorklet.ts, built by stringifying the pure helpers in hack.ts so tests cover the same math; saved neuro.box~ units and morph mutate values are converted by migrateFx on set/patch load.
- hack~ GEN patterns are a seeded 4x16 S&H table (hackPattern) rebuilt from params.seed in both worklet and screen, offset around the knobs by DEPTH and stepped from the transport anchor and glided by SMTH; knobs at 0 disable their stage. Step reseeding never resets stutter cursors or masks; replay freezes the capture ring and finishes by its captured length, with dry/replay edge crossfades and smoothed SHRT masks/amounts. All-zero stages bypass processing exactly; active processing retains its safety limiter, never loudness matching.
- Per-engine output trims live in src/audio/loudness.ts (ENGINE_TRIM) and multiply each voice's amp peak, so instruments sit level with the drums without touching tone or saved channel levels.
- hack~ gates to exact zero below -80 dBFS input and stops its pattern/flushes stutter memory on transport stop/pause (run port message), so it never sounds from silence.

- Euclidean and trance phrase writers are removed from the UI; their arp.ts helpers stay only so old sets that saved them still play.
- Chord FOLD (chord.fold, legacy chord.lead, default off) uses harmony.foldChord on absolute notes in the pad pitch's ±12-semitone window; only crossing tones fold by octaves, so root modulation stays audible without previous-chord register collapse.
- SYN filter models (clean.flt: CLEAN/LADDER/SEM/MS20) are native biquad stages with shared cutoff/env tracking in playClean; missing flt = CLEAN so old patches are unchanged. Browser oscillators are already band-limited, so no PolyBLEP worklet is used.
- PAD (src/audio/pad.ts + padPresets.ts) is its own engine kind with optional slot.pad filled by padParams(); voices are dry (no internal ensemble, LFO or reverb, presets never touch slot FX) so space comes only from the slot's own FX rack; saved motion/space fields are ignored; rings are capped by padRingCap.
- Sampler ADSR mode uses samplerAdsr (attack, punch hold, dB-linear decay) instead of the synth adsr, so short DEC tightens tails without losing the hit's loudness.
- Four group buses (groups.ts) receive grouped pads' post-pan output before master; grouped pads keep their own FX saved but bypassed, and the FX screen edits the group rack, so ungrouping restores the pad sound.
- SYN wavetables (src/audio/wavetable.ts) keep BASIC on native oscillators and play imported 2048-sample WAV frames as cached PeriodicWaves (raw WAV parse, no resampling) stored in their own IndexedDB; frame k stays on oscillator k % 2 so position moves never swap a sounding wave, and WAVE 0-3 remains the position so old sets load unchanged.
- digi.delay~ keeps its DSP in a self-contained DigiCore class embedded by source into the shared worklet bundle, so tests run the exact browser code; DUCK follows dry input only.
- SYN WT env (src/audio/wtEnv.ts, ADS + LOOP + optional SYNC, no release) is a pure level function; with the nad-wt worklet it is mirrored per sample inside the oscillator (env message), and only the PeriodicWave fallback uses a 16 ms timer, so sweeps never jitter.
- Imported wavetables play through the nad-wt worklet (src/audio/wtOsc.ts: continuous phase, per-octave band-limited mipmaps, per-sample smoothed frame interpolation, neighbour phase matching (flip harmonics >90° off the previous frame), energy-preserving frame blend from precomputed frame energies/dots, 15 ms position lag with a per-cycle slew cap); the PeriodicWave pair is only a fallback before worklets load, so sweeps never reset phase or click.
- SYN pitch decay is a per-voice ConstantSource signal summed into native and worklet detune AudioParams, separate from stereo detune edits, so live controls cannot interrupt its audio-clock exponential fall; the shared voice lifecycle stops and disconnects it.
- Factory wavetables (src/audio/wtFactory.ts, ids fx:<slug>) are 4 equal-RMS sine-phase keyframes built lazily from formulas and played through the BASIC native-oscillator crossfade with unnormalized PeriodicWaves, so they sweep as smoothly as BASIC; retired online-archive ids (wt:*-0) resolve to BASIC and are hidden from the library.
- Chord arp modes are Crave-style (musical.ts CHORD_ARPS/arpNote: UP1/2, DN1/2, U/D1 repeats ends, U/D2 legacy "updown", ORDR, RND) and legacy ids keep their meaning, so old sets play unchanged.
- adsr releases a note shorter than its attack at its gate from the reached level, and voice stop/release freeze the current curve value with holdAt (cancelAndHoldAtTime) before fading, so stolen or cut voices never snap and click.
- TRN is the synth engine with clean.osc = "terrain" (two nad-terrain orbiters in playClean, own TerrainPanel, XY = FREQ/FOLD), so wavetable SYN, filter/env code and saved sets stay shared and untouched.
- Rune sequencer: runes.ts (card data), runeHarmony.ts (PROG in KEY/SCL), runeCompiler.ts (pure) compile lanes into ordinary bank rows/pitch/mod lanes, so the scheduler never knows about runes; pitch counts toward the 3-target mod cap.
- Rune pad roles live on slot.padRole (missing = free via padRoleOf), so sets carry them and older sets load Free; the pad badge is a hit-zone inside the pad that never triggers sound.
- Rune cards carry optional rate (RUNE_RATES 2…1/32), explicit beat start and per-card targets; legacy cards infer contiguous starts. Layouts accept absolute pitch-class progressions or legacy degrees; compiled ModLane.targets resolves per step with at most three concurrent targets, preserving the shared scheduler and saved-set format.
- Pads sharing Bass alternate per phrase (card or bar) and pads sharing Arp per note group (AMT picks 1/2/4); done in compileRunes so the scheduler stays unchanged and loops are deterministic.
