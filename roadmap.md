# Groovebox roadmap
- [x] NAD branding: remove visible Max associations
- [x] Metallic feedback, spectral gate, sidechain, DJ filter and reverse delay
- [x] Choke groups, chord pads and lush poly synth
- [x] Per-pad A/B modulation sequencing and programmable gate rhythms
- [x] Global envelope time, tension riser, tape stop, reverse and stutter performance rack
- [x] Browser verification: effect/poly audio output, controls and set recall
- [ ] Real-phone verification: sustained performance, polyphony and touch capture effects
- [x] Stage 1: 16-pad rack, 16-step sequencer, master volume + scope
- [x] Per-slot instrument types: sampler, drum synth, Operator-style mono synth
- [x] Per-slot volume and pan
- [x] Per-slot effect chains
- [x] Modular effects: saturation, bitcrush, tape delay, reverb, chorus/flanger/phaser with envelope followers; connections set processing order
- [ ] Sequencer: 16 bars, grid resolution, note editing, velocity
- [ ] MIDI input (slots from note 36), pitched synth notes, MIDI learn, saved mappings
- [ ] Master chain: EQ -> Saturator -> Limiter, each switchable
- [x] Audio-reactive visualizer rack (scope, spectrum, meter, imager, spectro, hexdump, bitfield) + phrase randomizer
- [x] Performance: A/B pattern banks + 16ch mixer (vol/mute/solo)
- [x] Savable sets (local banks + JSON export/import)
- [x] Sample recall: device cache, built-in library, folder load, set bundles

- [x] Step grid doubles as mod sequencer, glide steps, 808 engine, acid drive, channel EQ, one-row partials, docked visualizers, phrase control touch-up
- [ ] Phone test of the new features
- [x] Oct batch: seq responsiveness, channel.eq~ fx (drop flat), master clipper+limiter, seq offset + loop shortener, MIDI learn, sampler grain mode, iPad layout
