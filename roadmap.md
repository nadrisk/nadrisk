# Groovebox roadmap
- [x] Stage 1: 16-pad rack, 16-step sequencer, master volume + scope
- [x] Per-slot instrument types: sampler, drum synth, Operator-style mono synth
- [x] Per-slot volume and pan
- [x] Per-slot effect chains
- [x] Modular effects: saturation, bitcrush, tape delay, reverb, chorus/flanger/phaser with envelope followers; connections set processing order
- [ ] Sequencer: 16 bars, grid resolution, note editing, velocity
- [ ] MIDI input (slots from note 36), pitched synth notes, MIDI learn, saved mappings
- [ ] Master chain: EQ -> Saturator -> Limiter, each switchable
- [ ] Audio-reactive visualizer (scope, spectrum, trippy visuals)
- [x] Performance: A/B pattern banks + 16ch mixer (vol/mute/solo)
- [ ] Savable sets (local banks + JSON export/import)
