# Three REESE visual previews

Create three example pictures first, then let you choose. No changes to the instrument in this stage.

## Preview directions

1. **Sound-system pressure** — a pixel speaker-cone cross-section and compressed sub-pressure bands, inspired by UK sound-system culture.
2. **Pirate-radio signal** — layered monochrome traces, signal offsets and controlled interference, inspired by underground radio.
3. **Dark 140 geometry** — a stark angular pressure emblem and stacked bass contours, inspired by underground dubstep sleeve art, without copying an existing artist or label identity.

## Keep the same screen

- Use your uploaded REESE screenshot as the source for each picture.
- Replace only the graphic inside the central frame; preserve the header, tabs, DET / DRFT / WID / SUB controls and screen proportions.
- Keep crisp, monochrome, square-edged pixels: no glow, gradients, soft illustration or additional text.
- Present all three at the same size and settings for a fair comparison.
- Inspect every picture for legibility, framing and accidental changes to the controls before presenting the choice.

## Technical details

Use image editing to produce three standalone PNG concept previews. These pictures are references, not assets to embed in the instrument. After you choose, a separate implementation plan will translate that direction into the existing 128×64 pixel drawing, responding to REESE parameters without adding audio processing or continuous animation.

## Scope

This approval covers the three pictures only. Sound, swing, REESE settings, performance behavior and the live interface remain unchanged.
